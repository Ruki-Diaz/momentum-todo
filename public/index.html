      Privacy & Data Transparency

      1. Local Workspace Storage

      When you use Momentum in Local Mode, your tasks, projects, tags, and preferences are stored in this browser on this device using localStorage. No local productivity data is sent to a server.

      2. Momentum Cloud & Authentication

      When you sign in to Momentum Cloud:

      • Authentication: Authentication is handled by Clerk.
      • Cloud Storage: Cloud workspace data is stored in a Neon PostgreSQL database.
      • Workspace Import: Importing a Local Workspace copies selected local data into the Cloud Workspace and does not automatically delete the local copy.

      3. Workspace Export & Deletion

      You can export a JSON backup of your workspace at any time. If you delete your Momentum Cloud account, your user records and cloud workspace data are deleted from the database.

      Feedback & Beta Notes

      Direct in-app feedback transmission requires an external feedback webhook or email integration that is not yet configured for this build.

      Please report issues or submit feedback through the project repository or release channels.

      Momentum Intelligence

      Productivity intelligence powered by OpenAI

      Momentum Intelligence assists with natural-language planning, daily scheduling, and task decomposition. Your privacy and data boundaries are strictly protected.

      What is shared with OpenAI

      • Relevant task titles and priority levels
      • Due dates and associated project names
      • Calculated completion metrics (aggregated counts)

      What is NEVER shared

      • Your account credentials, emails, or user IDs
      • Database identifiers or authentication tokens
      • Your full workspace dump or unrelated projects

      Requests are processed under OpenAI Zero Data Retention policies. Your workspace data is never used for model training. You can revoke this anytime in Settings.
